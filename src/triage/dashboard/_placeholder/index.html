The dashboard SPA is not in this install

The JSON API is live under /api — this placeholder is what the server falls back to when no built single-page app is present. Every route returns this page, which is why the dashboard looks empty rather than broken.

Build it from a source checkout

cd frontend && npm ci && npm run build
TRIAGE_DASHBOARD_STATIC="$PWD/dist" \
  uv run uvicorn triage.dashboard.app:app

From a checkout, just serve does this for you once frontend/dist exists.

Or install a wheel that carries it

Wheels built with node available ship the SPA inside the package, so this page never appears. A wheel built without node falls back to what you are reading.

The container image always carries the SPA: docker pull ghcr.io/ccd-ia/triage-pg:latest
